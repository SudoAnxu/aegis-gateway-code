# Aegis Research Track

This directory contains reproducible research artifacts for the agent-tool governance study. It is isolated from the production gateway implementation.

## Research question
Can runtime policy enforcement at the agent-tool boundary reduce unauthorized tool interactions while preserving legitimate task success with acceptable runtime overhead?

## Experimental systems
- B0: direct agent-to-tool execution.
- B1: simple allowlist authorization for agent, tool, and action.
- B2: Aegis with agent, tool, action, and parameter constraints.

## Minimum study
1. Formalize the system model and study assumptions.
2. Build a reproducible benchmark with independently checked and programmatically varied cases.
3. Compare B0, B1, and B2.
4. Measure security, legitimate-task utility, and runtime overhead.
5. Record code, benchmark, policy, and environment versions for every run.

Ablation, policy-complexity, hot-reload, and load experiments are optional extensions after the minimum study is stable.

Results must be generated by the experiment runner rather than manually entered.
